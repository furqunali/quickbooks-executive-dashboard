    Share with someone who does not use Claude

    1. Click Download dashboard file. It holds all the data shown here.
    2. Email it, or put it on Google Drive or WhatsApp.
    3. They download it and open it in Chrome, Edge or Safari. Slicers, drill-downs and Excel/PDF downloads all work.

    Google Drive cannot run a dashboard inside Drive itself; the file has to be downloaded first. For a one-click web link, drag the file onto app.netlify.com/drop.
